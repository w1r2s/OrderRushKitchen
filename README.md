# Order Rush Kitchen

Order Rush Kitchen is a fast-paced kitchen management game where the player takes customer orders, prepares ingredients, assembles dishes, and serves meals before the order timer runs out.

![Order Rush Kitchen main menu](Docs/Media/main-menu.png)

![Order Rush Kitchen gameplay loop](Docs/Media/gameplay-loop.gif)

## Gameplay Loop

1. Accept an order at the order counter.
2. Pick ingredients from kitchen stations.
3. Chop, fry, boil, or combine ingredients depending on the recipe.
4. Assemble the requested dish or drink.
5. Stage completed items at the delivery counter.
6. Complete the order before customer patience expires.

## Features

- Multi-item customer orders.
- Level progression with growing complexity.
- Ingredient selection UI for food and drinks.
- Chopping, frying, burning, pot cooking, and dish assembly flows.
- Delivery staging for completed order items.
- Desktop and mobile input support.
- English and Russian localization.
- Firebase Analytics and Crashlytics integration through infrastructure boundaries.

## Project Status

The core gameplay loop is playable on Android. Current work is focused on adding animations, final polish, balancing, presentation.
